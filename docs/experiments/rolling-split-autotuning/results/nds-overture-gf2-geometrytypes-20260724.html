The query & the question

Question: What geometry TYPES make up each Overture theme? Read straight from the 5-byte WKB header (byte-order + type code) WITHOUT decoding any coordinates — the shape vocabulary of the basemap. Scan-heavy: one scan of the geometry (WKB binary) column across all 5 themes (~48 GiB) + a tiny GROUP BY theme,header. All geometry ops (substring/hex on binary) run on GPU (0 CPU fallbacks, verified post-AQE).

WITH g AS (
    SELECT 'segment' AS theme, hex(substring(geometry,1,5)) AS hdr FROM segment
    UNION ALL SELECT 'connector', hex(substring(geometry,1,5)) FROM connector
    UNION ALL ... address, place, division ... )
  SELECT theme, hdr AS wkb_header,
    CASE hdr WHEN '0101000000' THEN 'Point' WHEN '0102000000' THEN 'LineString' ... END AS geometry_type,
    COUNT(*) AS features
  FROM g GROUP BY theme, hdr ORDER BY theme, features DESC

Clean result: the basemap's geometry vocabulary is just two shapes — roads (segment) are LineStrings, everything else (addresses, connectors, POIs, division points) is a Point. No non-standard/EWKB headers appeared (all standard OGC little-endian WKB). Honest note: division here is the type=division reference point, not the boundary polygon (those live in a separate division_area theme).
